# ClusBot 当前实现与联调边界

## 现行口径与交付边界

本页汇总当前设计、实现和联调边界。具体接口与操作条件以配套文档为准。

| 范围 | 当前后端 | 前端与 SVG 验收口径 |
| --- | --- | --- |
| 单助手与账号 | 多人版共用助手能力。登录身份决定个人消息、记忆、原始附件及任务归属。超管可跨账号查看和管理任务、运行状态及成果；可改标题，任务输入与交付要求由原账号维护，后续运行仍归原账号。首位超管只需用户名和密码，超管重置后临时密码登录须先改密。 | 普通用户默认进入自己的助手。超管在全站任务查询和确认卡中看清任务及所属账号。首次网页初始化、账号和强制改密已有后端流程，新版界面待联调。 |
| 助手工具 | ClusBot 内置工具调用现有鉴权业务接口。MCP 承接外部能力。工具入口支持明确命令和显式自然语言解析；少量问法可由支持卡片的消息客户端选择直接识别。写操作生成限时单次确认，目标、参数和会话固定，提交时复核权限和业务状态。 | SVG 展示查询卡、操作预览、取消、冲突、结果及可信表单回接。本机 Web 对话区接入 A2UI 1.0.0，macOS 封装复用同一 Web 客户端。确认与可信表单由固定控件承载。多人工作台已接入账号管理与可信改密入口。工具卡当前没有自动写入普通会话历史。 |
| 模型与绑定 | 已有提供方及模型目录、稳定默认引用、现有角色绑定与预览、脱敏运行回执。按业务覆盖、有序候补、通用本次覆盖仍是目标。单条隔离回复目前走单机入口。 | 区分当前配置、会话或任务的 Skill/MCP 绑定与指定执行的模型回执。实际模型标识未报告时显示请求模型及未报告状态。目录认证使用环境变量引用，回环地址可选无凭据；独立超时、业务覆盖等目标稿依赖后续接口。 |
| 资产和专用运行链 | 服务器模式支持普通任务（G1 周期 Goal 与 G2 Schedule 已下线）。专用基准、发现、工单运行链在本机模式；服务器模式的发现状态接口返回来源未就绪。 | 资产初始化提醒出现在个人助手会话入口，读取状态即可，界面不追加对话消息。本机资产、基准和发现操作稿按运行模式联调。 |
| 持久记录与恢复 | 多人账号独立存储及离线备份恢复已接入。工作任务和执行回执持久化；助手工具确认在进程内暂存，重启需要重新预览。跨对象回顾基线和客户端工具卡的恢复仍需端到端验收。 | 已受理、已执行、已验收分别显示。重连以目标业务对象的已记录状态为准，过期确认要求重新预览。 |
