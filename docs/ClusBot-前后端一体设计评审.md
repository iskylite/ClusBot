# ClusBot 当前实现与联调边界

## 现行口径与交付边界

本页汇总当前设计、实现和联调边界。具体接口与操作条件以配套文档为准。

| 范围 | 当前后端 | 对话与界面验收口径 |
| --- | --- | --- |
| 单助手与账号 | 多人版共用助手能力。登录身份决定个人消息、记忆、原始附件及任务归属。超管可跨账号查看和管理任务、运行状态及成果；可改标题，任务输入与交付要求由原账号维护，后续运行仍归原账号。首位超管只需用户名和密码，超管重置后临时密码登录须先改密。 | 普通用户默认进入自己的助手。超管在全站任务查询和确认卡中看清任务及所属账号。Web 默认和 App 复用首次超级管理员初始化、登录、强制改密与按账号隔离；无共享口令路径。 |
| 助手工具 | ClusBot 内置工具调用现有鉴权业务接口。MCP 承接外部能力。工具入口支持明确命令和显式自然语言解析；少量问法可由支持卡片的消息客户端选择直接识别。写操作生成限时单次确认，目标、参数和会话固定，提交时复核权限和业务状态。 | 对话可直接展示查询卡和业务证据；确认与凭据表单由同一对话中的可信宿主控件承载。专用页面不是先验验收条件。macOS 复用同一 Web 客户端。通用工具卡和脱敏操作回执还需要跨刷新恢复。 |
| 模型与绑定 | 已有提供方及模型目录、稳定默认引用、现有角色绑定与预览、脱敏运行回执。已支持业务/角色配置与明确授权的有序候补。按本轮实际路由核对输入能力与数据出域，不能拿全局默认能力代替；单条隔离回复仅发送本条明确输入。 | 区分当前配置、会话或任务的 Skill/MCP 绑定与指定执行的模型回执。实际模型标识未报告时显示请求模型及未报告状态。目录认证使用环境变量引用，回环地址可选无凭据；独立超时、业务覆盖等目标稿依赖后续接口。 |
| 资产和专用运行链 | 发现按账号保存授权与观测、从实例目录查已批准连接。NHC 独立于 Slurm；无覆盖不能推断恢复。基准须通过具体提供方的参数、作业和证据合同验收。尚未提供账号化派发或回调的能力明确标为不可用，不退回共享口令运行。 | 在对话里验收来源缺失、只读授权、部分发现、候选纳管、复检和基准回执；确认不同用户、停用状态与连接撤权均不可越权。 |
| 持久记录与恢复 | 多人账号独立存储及离线备份恢复已接入。工作任务和执行回执持久化；助手工具确认在进程内暂存，重启需要重新预览。跨对象回顾基线和客户端工具卡的恢复仍需端到端验收。 | 已受理、已执行、已验收分别显示。重连以目标业务对象的已记录状态为准，过期确认要求重新预览。 |
