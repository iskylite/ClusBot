日常运维的默认入口为个人助手对话。Cluskit2-MCP 提供受控发现、只读健康检查和基准作业接口；不需要 Slurm 环境。可用性以[实际联调边界](ClusBot-前后端一体设计评审.md)和对应验收场景为准，不能用工具目录、原型画板或结构声明代替实测。
